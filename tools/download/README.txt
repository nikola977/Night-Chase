Car Driving World 1.0.0 (Windows 10/11, 64-bit)
===============================================

Install
-------
1. Unzip the folder anywhere you like (for example into Documents). No installation is needed.
2. Start "Car Driving World.exe". The program is not signed, so Windows SmartScreen may show
   "Windows protected your PC" the first time: click "More info", then "Run anyway".
3. The very first start takes about a minute while the shaders are prepared. After that it loads
   in a few seconds.

Needs a graphics card with Vulkan 1.2 support (current drivers).

Keys: WASD drive, Space handbrake, Esc menu (settings, all keys), G garage, M map, P photo mode,
Tab camera. All keys are listed in the pause menu under Settings > Controls.

This download contains only car models with a CC BY license (BMW M3 E30, M3 GTS E92, M5 F90,
M4 CSL, Audi S3 in traffic, gas station). Credits: CREDITS.txt and in the game under
Garage > Credits.


Installieren (Deutsch)
----------------------
1. Den Ordner an einen beliebigen Ort entpacken (z. B. in „Dokumente“). Eine Installation ist nicht nötig.
2. „Car Driving World.exe“ starten. Das Programm ist nicht signiert, deshalb zeigt Windows SmartScreen
   beim ersten Start evtl. „Der Computer wurde durch Windows geschützt“: „Weitere Informationen“ klicken,
   dann „Trotzdem ausführen“.
3. Der allererste Start dauert etwa eine Minute, weil die Shader vorbereitet werden. Danach lädt das
   Spiel in wenigen Sekunden.

Gebraucht wird eine Grafikkarte mit Vulkan-1.2-Unterstützung (aktuelle Treiber).
